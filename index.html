03. System & Pipeline

실시간 오디오 반응형 무용 파이프라인

Ubuntu & Python Core

시스템 데이터 흐름

  • Audio Source: 성악가 보컬 및 연주 (2ch)
  • Python Server: FastAPI 기반 실시간 분석 (Volume, Pitch)
  • Protocol: OSC (UDP) → TouchDesigner, WebSocket
  • Control UI: iPad Operator Web Panel

핵심 기술 스택

  • Audio Engine: PyAudio, sounddevice, librosa
  • Backend: Python 3.11, FastAPI, python-osc
  • Visualization: TouchDesigner, Blender (아바타/캘리그라피)
  • Frontend UI: HTML5 / CSS3 / JS
