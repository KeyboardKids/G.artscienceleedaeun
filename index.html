02. Artistic Storyline

3장 구성의 예술적 서사

공연 시놉시스
Static → Energy

1장. 소리의 탄생

작은 소리가 물의 입자가 되어 유등천의 흐름을 그려냅니다. 두 연주자의 소리가 각기 다른 색깔과 온도의 빗줄기가 되어 무대 바닥에 쌓여갑니다.

Voice → Avatar

2장. 두 흐름의 대화

두 소리가 만나 갑천과 유등천이 교차하듯 위엄 있게 얽힙니다. 가야금의 속주(Onset)와 성악/플루트 음높이(Pitch)에 따라 빗줄기 밀도와 파동이 고조됩니다.

Harmony & Completion

3장. 공존 (금강)

하나의 울림이 버드나무를 흔들고 온 풍경이 숨을 쉽니다. 비가 그치고 빗물이 모여 만든 거대한 강물이 바다를 향해 흘러가는 장엄한 완성을 이룹니다.

성악 · 가야금 · 플루트 · TouchDesigner 2 / 5

03. System & Pipeline

실시간 오디오 반응형 파이프라인

Ubuntu & Python Core

시스템 데이터 흐름

  • Audio Source: 가야금 / 성악 / 플루트 (2ch 오디오 인터페이스)
  • Python Server: FastAPI 기반 실시간 분석 (Volume, Pitch, Rhythm, Spectral)
  • Protocol: OSC (UDP) → TouchDesigner, WebSocket → Operator UI
  • Control UI: 백스테이지 태블릿(iPad) Operator Web Panel

핵심 기술 스택

  • Audio Engine: PyAudio, sounddevice, librosa
  • Backend: Python 3.11, FastAPI, Uvicorn, python-osc
  • Visualization: TouchDesigner, Blender (Physics Simulation)
  • Frontend UI: HTML5 / CSS3 / JS (iPad Safari 최적화)
