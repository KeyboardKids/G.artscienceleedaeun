02. Artistic Storyline

3장 구성의 예술적 서사

1장. 소리의 탄생

작은 소리가 물의 입자가 되어 유등천의 흐름을 그려냅니다. 소리가 빗줄기가 되어 무대에 쌓입니다.

Voice → Avatar

2장. 두 흐름의 대화

갑천과 유등천이 교차하듯 얽힙니다. 가야금의 속주와 성악 음높이에 따라 파동이 고조됩니다.

Harmony & Completion

3장. 공존 (금강)

하나의 울림이 버드나무를 흔들고, 모인 강물이 바다를 향해 흘러가는 장엄한 완성을 이룹니다.

03. System & Pipeline

실시간 오디오 반응형 파이프라인

Ubuntu & Python Core

시스템 데이터 흐름

  • Audio Source: 가야금 / 성악 / 플루트 (2ch)
  • Python Server: FastAPI 기반 실시간 분석 (Volume, Pitch)
  • Protocol: OSC (UDP) → TouchDesigner, WebSocket
  • Control UI: iPad Operator Web Panel

핵심 기술 스택

  • Audio Engine: PyAudio, sounddevice, librosa
  • Backend: Python 3.11, FastAPI, python-osc
  • Visualization: TouchDesigner, Blender
  • Frontend UI: HTML5 / CSS3 / JS
